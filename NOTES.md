# Журнал работы

## Решения, которые неочевидны

- **Прогресс хранится по номеру слова** из словаря, а не по тексту. Словарь можно
  перегенерировать (ударения, исправления), прогресс останется.
- **Ударения не мешают поиску и озвучке.** Поиск сворачивает все диакритики
  (NFD + удаление знаков), озвучка снимает только знаки ударения, а caron/acute
  после c, s, z оставляет — это č, ć, š, ž.
- **Service worker — network first для всего.** Приложение маленькое, а новый
  `words.js` должен приехать при следующем запуске без смены версии кэша.
- **Выученное слово не «разучивается».** «Снова» на выученном слове сбрасывает
  интервал, но группа остаётся пройденной — иначе группы мигали бы туда-обратно.
- **Оценок три:** «Повторить», «Знаю» и «Изучено». Свайп вправо — «Знаю», влево —
  «Повторить», и на вопросе, и на ответе. «Изучено» ставит флаг `k`: слово сразу
  выучено, следующий показ — через 30 дней. Флаг нужен, чтобы слово не «разучилось»,
  если в настройках поднять число дней.
- **Страница не прокручивается и не зумится.** `body` зафиксирован, прокручивается
  только сам экран (`.view`) или ответ внутри карточки. Зум отключён в viewport,
  `touch-action: manipulation` и `gesturestart`.
- **Прогон** (когда на сегодня в группе ничего не осталось) не меняет расписание.

## Грабли

- **SVG-иконкам задавать `width`/`height` атрибутами.** Safari на iPhone показал
  пустую кнопку «Назад», когда размер иконки шёл только из CSS; в Chromium всё
  было видно. Playwright-WebKit на macOS 14 не запускается, так что проверить
  такое можно только на телефоне.
- **Нижняя панель — не `position: fixed`.** На iOS она уезжала при прокрутке;
  теперь `body` — flex-колонка, экран прокручивается внутри, панель — строка под ним.

- **Обновления.** GitHub Pages отдаёт `max-age=600`, и `fetch` из service worker
  брал страницу из HTTP-кэша — поэтому `cache: "no-cache"`. А iOS не перезапускает
  приложение с домашнего экрана, а будит его, поэтому при каждом возврате вызывается
  `registration.update()`. **На каждом релизе поднимать `VERSION` в `sw.js`** —
  только смена `sw.js` заставляет открытое приложение перезагрузиться (не посреди
  сессии карточек).

- На iPhone хранилище Safari и приложения с домашнего экрана — разные. Учиться
  надо из иконки на домашнем экране, иначе прогресс останется в Safari.
  Кроме того, Safari чистит данные сайтов, не открытых 7 дней; на установленное
  приложение это не распространяется.
