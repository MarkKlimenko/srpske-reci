# Srpske reči

Карточки сербских слов по частотному словарю (3428 слов), как в Anki.
Один `index.html` без сборки, работает офлайн и ставится на домашний экран.

- Слова разбиты на группы по 20, по порядку частоты. Текущая группа учится, пока
  все её слова не выучены; перейти дальше можно в любой момент.
- Слово выучено, когда его вспомнил («Знаю» или «Легко») в N разных дней
  (по умолчанию 2, меняется в настройках).
- Интервалы повторения — упрощённый SM-2; учебный день начинается в 04:00.
- Прогресс хранится только на устройстве (`localStorage`); копия — файлом через
  настройки.

## Словарь

`words.js` собирается из Markdown-словаря:

```bash
node tools/build-words.mjs                 # ~/workplace/my/docs-2/me/serbia/language/dictionary
node tools/build-words.mjs /path/to/dir    # другой путь
```

Прогресс привязан к номеру слова, поэтому правки текста (ударения, переводы)
его не трогают. Перестановка номеров — трогает.

## Запуск локально

```bash
./start.sh          # http://localhost:8778
./start.sh --lan    # плюс доступ с телефона в той же Wi-Fi
```
