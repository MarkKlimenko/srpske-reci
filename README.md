# Srpske reči

Карточки сербских слов, как в Anki: частотный словарь (3428 слов) и 37 тем
(ещё 552 слова), всего 3980. Прогресс по слову общий, где бы оно ни встретилось.
Один `index.html` без сборки, работает офлайн и ставится на домашний экран.

Открыть: https://markklimenko.github.io/srpske-reci/ (GitHub Pages с ветки `main`;
после `git push` обновляется за минуту-две).

- Каталог: частотный словарь — группы по 20 по порядку частоты; темы — по блокам,
  каждая тема делится на равные группы не больше 20 слов.
- Слова разбиты на группы по 20, по порядку частоты. Текущая группа учится, пока
  все её слова не выучены; перейти дальше можно в любой момент.
- Слово выучено, когда его вспомнил («Знаю» или «Легко») в N разных дней
  (по умолчанию 2, меняется в настройках).
- Свайп вправо — «Знаю», влево — «Повторить»; кнопка «Изучено» сразу считает
  слово выученным.
- Кнопка «Примеры» на лицевой стороне карточки показывает фразы-примеры прямо на вопросе,
  на языке вопроса.
- Интервалы повторения — упрощённый SM-2; учебный день начинается в 04:00.
- Прогресс хранится только на устройстве (`localStorage`); копия — файлом через
  настройки.

## Грамматика

`grammar.js` собирается из курса грамматики (`grammar.md`, `grammar/NN-*.md`,
`cheatsheet.md`):

```bash
node tools/build-grammar.mjs               # ~/workplace/my/docs-2/me/serbia/language
```

Упражнения разбираются по номерам заданий и ответов. Типы: выбрать вариант
(варианты в скобках «(a / b)» или «X или Y» в заголовке), вписать (пропуски `___`
и короткие ответы), перевод с самопроверкой, открытые «О себе». Если число заданий
и ответов не сходится, упражнение показывается текстом с кнопкой «Показать ответы».

## Макеты

`mockups.html` — все экраны на одной странице, открывается в любом браузере.
Источник — канвас https://claude.ai/artifact/NLiRKrASgi6eC3BK8LEBzD; файл
пересобирается из его артбордов: `python3 tools/build-mockups.py <папка с canvas.json>`.

## Словарь

`words.js` собирается из Markdown-словаря:

```bash
node tools/build-words.mjs                 # ~/workplace/my/docs-2/me/serbia/language
node tools/build-words.mjs /path/to/dir    # другой путь (с dictionary/ и themes/ внутри)
```

Прогресс привязан к номеру слова, поэтому правки текста (ударения, переводы)
его не трогают. Перестановка номеров — трогает.

## Запуск локально

```bash
./start.sh          # http://localhost:8778
./start.sh --lan    # плюс доступ с телефона в той же Wi-Fi
```
